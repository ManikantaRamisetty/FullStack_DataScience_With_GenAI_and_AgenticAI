What is Seaborn and why do we need it?

Seaborn is a Python visualization library built on top of Matplotlib.

Think of the relationship like this:

Python Data
    ↓
Pandas
    ↓
Data Analysis
    ↓
Seaborn
    ↓
Statistical Visualization
    ↓
Understand Patterns → Build Better ML Models

The key point is:

Seaborn is not required to build an ML model, but it is extremely useful for understanding your data before building the model.
